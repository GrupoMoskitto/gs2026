Da tela ao código

Estrutura sugerida (Expo Router). Pode mudar quando o projeto for criado.

TelaArquivo (sugestão)APIO que a nota cobra
Identificaçãoapp/index.tsxNenhumaIdentificação lembrada ao reabrir
Mapa (proposta)app/(tabs)/mapa.tsxGET /api/relatos, GET /api/previsoesLocalização como recurso nativo
Relatosapp/(tabs)/relatos.tsxGET /api/relatosLista com carregando, erro e vazio
Detalheapp/relato/[id].tsxGET /api/relatos/{id}Navegação com 3 telas ou mais
Novo relatoapp/novo.tsxPOST /api/relatosFormulário validado, localização e permissão tratada
Riscoapp/(tabs)/risco.tsxGET /api/previsoesIntegração com o modelo de IA
  • Chamadas à API ficam em services/, com dados de exemplo (mock) quando a API não responde.
  • Validação do formulário em funções puras (validation/), fáceis de testar.
  • TypeScript estrito, sem any. Os tipos Relato e PrevisaoRisco seguem o formato do AGENTS.md, seção 4.
  • Texto mínimo de 14 px, contraste alto e risco sempre com rótulo em texto, nunca só cor.
