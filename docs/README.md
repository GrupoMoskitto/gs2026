## Resumo em 30 segundos

- A equipe (até 5 alunos) escolhe **um problema real da cidade**, com uma pessoa real que convive com ele.
- Constrói o protótipo de **uma única CitizenTech**, que atravessa todas as disciplinas. Cada disciplina entrega uma parte, e as partes precisam conversar entre si.
- Não precisa construir tudo, mas o que for construído deve **funcionar e fazer sentido junto**.
- Todo projeto deve identificar os **ODS da ONU** a que se conecta (obrigatório).
- Cada disciplina corrige e dá nota de 0 a 10, individualmente, em até uma semana após o encerramento.
