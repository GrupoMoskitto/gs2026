# Ficha da CitizenTech

> Sugestão do PDF. Preencher antes de programar e colocar **no início do README** do repositório. A ficha responde às seis perguntas do briefing.
> Algumas disciplinas (Mobile, Operating Systems) exigem a Ficha no README.

## Modelo

```markdown
# <Nome da CitizenTech>

| Campo | Resposta |
|---|---|
| **Nome da CitizenTech** | |
| **Cidade e bairro** | |
| **Cidadão beneficiado** | (quem é, e quem é a pessoa real que foi ouvida) |
| **Problema, em uma frase** | |
| **Como funciona** | |
| **O que cada parte faz** | (backend, mobile, desktop, ML, ESP32, infra, segurança, arquitetura) |
| **Link do repositório** | |
| **Indicador de impacto** | (como medir o resultado) |
| **ODS conectados** | (quais, e como contribui para as metas) |

## Equipe

| Nome | RM |
|---|---|
| | |
```

## Mapeamento com as seis perguntas do briefing

| Pergunta | Campo da ficha |
|---|---|
| 1. Quem é o cidadão beneficiado? | Cidadão beneficiado |
| 2. Qual problema será resolvido? | Problema, em uma frase |
| 3. Como a solução funcionará? | Como funciona |
| 4. Quais tecnologias serão empregadas? | O que cada parte faz |
| 5. Quem participará do ecossistema? | Cidadão beneficiado, O que cada parte faz |
| 6. Como o impacto poderá ser medido e ampliado? | Indicador de impacto, ODS conectados |
